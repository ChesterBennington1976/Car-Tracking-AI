# Система анализа безопасного стиля вождения на основе компьютерного зрения

## Описание проекта

Программа анализирует дорожное видео и помогает выявлять потенциально опасные манёвры автомобилей.
Для обнаружения транспорта используется предобученная модель Ultralytics YOLOv8, для сопровождения объектов между кадрами применяется ByteTrack.
Система отслеживает траектории движения машин, хранит историю координат и фиксирует резкие боковые перестроения.

## Основные возможности

- загрузка видеофайла
- отображение первого кадра
- детекция автомобилей и другого транспорта
- трекинг объектов с уникальными ID
- подсчёт нарушений
- определение резких перестроений
- логирование событий в интерфейс
- техническое логирование в отдельный файл
- пауза и продолжение обработки
- остановка анализа
- сохранение логов интерфейса

## Как работает алгоритм

1. YOLO находит транспортные средства на каждом кадре.
2. ByteTrack присваивает объектам ID и поддерживает их между кадрами.
3. Для каждого ID сохраняется история координат центра bounding box.
4. По траектории рассчитывается боковое смещение по оси X.

«Боковое смещение по оси X» — Это просто движение вправо-влево. 
Представь видео: машина едет вверх по экрану (ось Y). 
Если она резко прыгает вправо или влево — это изменение координаты X. 
Программа видит: «Опа, X изменился слишком быстро — значит, это резкое перестроение».

5. Если смещение превышает заданный порог, фиксируется нарушение.

## Используемые технологии:

- Python
- PyQt5

PyQt5 — Это библиотека для создания кнопок, окошек и меню. 
Благодаря ей программа выглядит как приложение, а не просто черный экран с кодом.

- OpenCV

OpenCV — Самая главная библиотека для работы с видео. 
Она умеет открывать видеофайл, резать его на кадры 
и рисовать на них квадратики.

- Ultralytics YOLOv8
- ByteTrack

## Установка:

```bash
pip install pyqt5 opencv-python ultralytics numpy
```

Или так: 

```bash
python -m pip install pyqt5 opencv-python ultralytics numpy
```

Это команда для компьютера, 
чтобы он скачал нужные детали 
(библиотеки) из интернета. 

Без них программа не поймет, 
что такое «нейросеть» или «окно».

## Запуск

python main.py

## Структура проекта

- `main.py` — точка входа в приложение
- `app/main_window.py` — логика интерфейса PyQt5
- `app/video_analyzer.py` — анализ видео, детекция, трекинг и анализ траекторий
- `app/tech_logger.py` — техническое логирование
- `name.log` — файл технических логов

## Примечание

- В проекте используется предобученная модель YOLO.
- Обучение модели в рамках программы не выполняется.

Это нормально. 
Обучать нейросеть с нуля — это месяцы работы 
и мощные сервера. 

Ваня взял готовую «умную» модель (YOLO), 
которая уже умеет узнавать машины, 
и просто научил её анализировать их маршрут. 
Это стандарт для диплома.

- Основной упор сделан на анализ траектории движения и выявление резких перестроений.
